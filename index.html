Course Description

This course covers the modern web technologies and standards used to create rich interactive web sites and applications. Students will learn the essentials of HTML5 and CSS3 to build modern websites, as well as the fundamental concepts of modern cilent-side and server-side scripting, Other topics include accessibility, search engine optimization (SEO), performance optimization, and responsize design.

Prerequisites: None

Credit Hours: 3

Course Outcomes

Students completing this course will be able to:

  • Understand the structure and functionality of the World Wide Web and internet protocols.
  • Create valid, semantically structured web pages using HTML5.
  • Apply modern CSS3 styling techniques for layout, typography, and responsive design.
  • Implement basic client-side scripting concepts to enhance web page interactivity.
  • Publish and maintain websites using standard web hosting and version control tools like Git and GitHub Pages.

Course Objectives

At the conclusion of this course, each student will:

  • Recall and explain the core standards established by the W3C and other governing bodies.
  • Demonstrate proficiency in debugging and validating HTML and CSS code.
  • Construct mobile-friendly, accessible layouts adhering to modern usability principles.
  • Integrate and manage project assets within a clean directory structure.
  • Analyze web performance metrics and optimize digital media for fast loading times.
